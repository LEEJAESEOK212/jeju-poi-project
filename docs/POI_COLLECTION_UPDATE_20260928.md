# 제주 POI 추가 수집·정제 기록

이 문서는 기존 운영 상태 자동화 기록 이후 이어진 추가 수집, 주소 검증, 분류, 콘텐츠 조사와 통신 개선을 정리한다. 숫자는 해당 단계의 로컬 산출물·작업 기록 기준이며 각 단계의 모집단이 다르다. 목표와 완료 실적을 구분한다.

## 목표와 데이터 기준

목표는 기존 데이터와 중복되지 않는 관광객용 신규 POI 10,000건이다. 원천 행 수를 그대로 신규 성과로 세지 않는다. 음식점·숙박·카페·일반 상가는 이미 대량 수집했으므로 생활편의, 여행지원, 체험, 공공시설로 범위를 확장했다.

| 단계 | 기록상 행 수 | 의미 |
|---|---:|---|
| 기존 저장소 운영 상태 기준 | 57,989 | 이전 버전의 상태 판정 모집단 |
| 도서관 반영 통합본 | 58,237 | 당시 수집 작업 인계 기준 |
| 금연구역·주소 교차 검증 기준본 | 71,520 | 다음 추가분의 기준 파일 |
| 카카오 신규 추가분 | 3,257 | 해당 기준본에 대조해 남긴 추가분 |
| AED 추가분 | 1,352 | 원천 1,353건에서 완전 중복 1건 제외 |
| 신규 추가분 합계 | 4,609 | 3,257 + 1,352 |
| 통합 산출물 | 76,129 | 71,520 + 4,609 |
| 네이버 상세 조사 대상 | 3,234 | 추가분에서 AED 1,352, ATM 23 제외 |

76,129는 수집 통합 파일의 행 수다. 이전 상태 판정의 서비스 대상 50,732와 비교해 곧바로 증가율을 계산할 수 없다. 신규 10,000건 확보 완료나 모든 행의 콘텐츠 검수 완료를 의미하지 않는다.

## 공공·관광 원천 조사

버스정류소, 마을안전시설, 오름, 템플스테이, 읍면동사무소, 생태관광지, 버스터미널, 전시관, 공공심야약국, 외국인환자 유치 의료기관, 자연유산, 곶자왈, 응급의료기관, 문화재, 보건시설, 도서관 등을 기존 데이터와 대조했다. 심야버스·시내버스 노선 같은 자료는 노선과 실제 장소를 구분하고, 일대일 장소로 환원할 근거 없이 행을 추가하지 않는 방향으로 정리했다.

동일 시설의 새 정보는 콘텐츠·태그 보강에 사용했다. 예를 들어 오름 설명, 심야약국 운영 특성, 외국인환자 유치 여부는 원천 기준일과 시설 동일성을 함께 검토한다. 단순 중복 제거로 새 사실까지 버리지 않는 것이 목적이다.

비짓제주 API에서 5,310개 고유 콘텐츠를 확보했다. 첫 조회 전체 건수 5,321과 차이가 있어 페이지 변동 중 누락 가능성을 기록했다. 관광지 1,311개 대조 결과는 다음과 같다.

| 분류 | 건수 |
|---|---:|
| 정확한 이름·150m 이내 | 583 |
| 유사 이름·60m 이내 | 61 |
| 근접 장소 상세 검토 | 391 |
| 반경 150m 주변 일치 없음 | 244 |
| 좌표 없음 | 32 |

244건은 신규 후보이며 확정 신규가 아니다. 축제·행사 908건과 좌표 없는 테마여행 기사를 상설 POI로 일괄 편입하지 않았다. 이 원천만으로 신규 10,000건을 확보할 수 없다고 판단했다.

## 지도 API 수집과 중복 판정

제주 전역을 대상으로 쇼핑·빈티지, 세탁·미용·사우나·환전·ATM·짐보관, 렌터카·대여·여행사·전세버스, 공방·낚시·다이빙·서핑·승마·요트 등으로 검색 범위를 확장했다. 검색 기반 수집이므로 제주에 존재하는 모든 장소를 빠짐없이 수집했다는 뜻은 아니다.

후보 생성에는 이름 정규화, 주소, 공간 근접, 전화번호를 사용했다. 판정에서는 카카오 ID 외에도 지점·별칭·주소 표기 차이·좌표와 장소 역할을 함께 검토했다. 같은 건물의 영업시설과 금연구역·화장실·ATM·AED는 기능이 다르므로 위치가 같다는 이유만으로 중복 처리하지 않는다. 같은 전화번호도 본사 공용번호일 수 있어 단독 확정 근거로 일반화하면 안 된다.

ATM 후보 수에 대한 재검토 요청을 받아 초기 후보 수를 최종 신규 수로 사용하지 않고, 최종 기준본으로 다시 대조하는 절차를 적용했다. 근접·동명·동일 주소 후보는 확정 신규와 분리한다. 대조표에는 원천 ID, 기존 place_id, 판단 이유, 반영 필드와 보류 사유를 남기는 것을 원칙으로 삼았다.

## 카테고리·주소·좌표

- 서브카테고리 차트와 통합본의 ID 대응을 확인하고 변경분을 먼저 확정했다. 공방은 기존 정책에 맞춰 교육시설의 체험학습장으로 정리했다.
- 금연구역은 별도 분류로 관리했다. AED 분류도 추가 후 기존 분류 변경 여부를 점검하는 대상으로 삼았다.
- 도로명·지번이 비어 있는 경우를 구분했다. 버스정류소 등은 도로명 건물번호가 없는 경우가 있으므로 인근 건물 주소를 대신 채우지 않는다.
- 좌표 역조회와 원본 주소가 충돌하면 사용자 결정에 따라 원본 주소를 우선하고 정방향 지오코딩으로 좌표·도로명을 재검증했다.
- 네이버와 카카오 검색을 교차 사용하되 다른 주소나 여러 후보가 나오는 결과를 바로 반영하지 않는다. 조회 실패와 이미 동일하여 변경하지 않은 경우를 구분한다.
- 원본 형식과 place_id, merge_key, 분류 ID, 좌표 범위, geometry 대응 및 중복을 검증하는 통합 절차를 남겼다.

AED 출처는 [전국자동심장충격기표준데이터](https://www.data.go.kr/data/15021103/standard.do)로 수정했다. 신규 콘텐츠의 `_x000D_` 등 제어문자 흔적을 정리하고, AED 설치 위치·이용 시간·기기 정보를 문장으로 구성했다. 같은 요일 시간은 월~금처럼 묶고 다른 시간대는 따로 남겼다. 전체 통합본 대신 신규 추가분에서 먼저 콘텐츠를 검토하도록 작업 단위를 줄였다.

## 네이버 조사: 장소 확인과 콘텐츠 보강의 구분

첫 우선순위 조사 857건에서 자동 확정 182건, 검토 45건, 불일치 28건, 검색결과 없음 602건으로 집계됐다. 미확정 675건 재조회는 확정 391건, 검토 12건, 불일치 112건, 지역검색결과 없음 160건이었다. 누적 확정 후보 573건 중 주소 근거가 부족한 59건을 제외해 514건으로 낮추고, 상호 불일치·주소 일치 26건 중 24건을 재검토해 538건으로 정리한 단계가 있었다.

그러나 이 수치는 장소 매칭 단계 결과다. 업종·지역만으로 만든 일반적인 소개문은 새로운 이용 정보를 확보한 결과가 아니어서 최종 콘텐츠로 인정하지 않았다. 초기 514/538건의 템플릿 보강 파일은 콘텐츠 품질 완료 성과에서 제외한다.

플레이스 상세 페이지 직접 조회는 차단되어 중단했다. 최종 수집 방식은 기존에 사용하던 API HUB의 지역·웹·블로그 검색과 업종별 연관검색어, 접근 가능한 본문 수집으로 정리했다. 전체 대상 3,234건에 대해 검색 출처, 본문, 장소 동일성 근거를 수집하고 이후 확인된 사실만 콘텐츠·태그에 반영한다.

자동 `본문근거확보` 표시는 상호와 주소가 문맥상 발견됐다는 신호다. 실제 서비스 설명 확보, 최신성 또는 최종 승인과 구분한다. 오래된 블로그의 가격·시간, 여러 지점이 섞인 글, 같은 주소의 다른 매장 정보는 추가 검토가 필요하다.

## 실행 효율과 현재 범위

완료 결과 및 검색·본문 캐시를 SQLite에 저장해 중단 후 재개할 수 있도록 했다. 제한된 작업자 풀을 적용한 뒤, API 응답 대기가 공용 잠금을 점유하는 구간을 분리해 요청이 겹쳐 진행되도록 수정했다. 요청 간격·예산·429 대기는 전역으로 유지했다.

사용자가 제공한 개선 후 마지막 화면은 328/3,234건이다. 이 기록은 전체 수집 완료를 입증하지 않는다. 처리량 계산과 자소서 문안은 [통신 개선 사례](HTTP_CONCURRENCY_CASE_STUDY.md)에 별도로 정리했다.

공개 저장소에는 실행 코드와 작업 기록·집계·화면 증거를 제공한다. 인증키, 고객별 실행 데이터, 원문 본문 캐시와 전체 대화는 공개하지 않는다.
