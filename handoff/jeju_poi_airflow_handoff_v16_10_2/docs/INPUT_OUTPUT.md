# 입력과 출력

## 입력

현재 POI CSV는 기존 서비스 데이터의 열 구성을 그대로 사용한다. 파이프라인은 입력 열을 임의로 공개 출력에 추가하지 않는다.

필수 파일은 다음과 같다.

| 종류 | Airflow Variable | 형식 |
|---|---|---|
| 현재 POI 원본 | `JEJU_POI_CURRENT_CSV` | UTF-8 BOM CSV |
| 행안부·공공 원천 증거 | `JEJU_POI_MOIS_EVIDENCE_JSONL` | JSONL |
| 카카오 장소 증거 | `JEJU_POI_KAKAO_EVIDENCE_JSONL` | JSONL |

신규 납품 CSV는 선택 사항이며 `JEJU_POI_NEW_CSV`에 지정한다.

## 상태 값

| 상태 | 의미 |
|---|---|
| 영업 | 행정 원천 또는 카카오 동일 장소 확인 |
| 운영 | 고정시설·인프라에 변경 근거 없음 |
| 확인 필요 | 카카오 미발견 또는 행정 후보 미해결 |
| 폐업 | 행정 원천에 명시적 폐업 근거 있음 |

## 출력 검증

- 서비스 파일에는 `영업`, `운영`만 존재해야 한다.
- 최종 상태 파일과 판정보존 목록은 같은 행 수와 상태 분포여야 한다.
- 판정보존 목록의 `status_reason_code`는 비어 있으면 안 된다.
- `place_id`는 각 출력 파일 안에서 중복되면 안 된다.
