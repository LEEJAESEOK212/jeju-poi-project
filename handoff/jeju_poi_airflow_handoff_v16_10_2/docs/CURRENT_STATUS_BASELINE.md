# 현재 검증 기준 결과

아래 값은 이 인수인계본을 만들 때 검증한 최신 실행 결과다. 입력 원본 또는 증거 파일이 달라지면 결과도 달라질 수 있다.

| 상태 | 건수 |
|---|---:|
| 영업 | 35,890 |
| 운영 | 14,842 |
| 확인 필요 | 5,675 |
| 폐업 | 1,582 |
| 전체 | 57,989 |

서비스 업로드 대상은 영업·운영 합계인 50,732건이다.

확인 필요는 카카오 미발견 5,316건과 행정 후보 미해결 359건으로 구성된다. 폐업 1,582건은 모두 명시적 행정 원천 폐업 근거로 처리했다.
