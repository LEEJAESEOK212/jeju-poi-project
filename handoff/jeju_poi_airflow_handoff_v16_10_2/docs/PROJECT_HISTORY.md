# 작업 정리

## 목적

제주 POI 원본을 기준으로 영업 상태를 판정하고, 서비스에 올릴 대상과 전체 상태·판정 근거를 분리해 생성한다.

## 상태 판정 정책

1. 명시적 행정 원천 폐업 근거가 있을 때만 폐업 처리한다.
2. 카카오 후보는 이름·주소·장소 역할이 같은 경우에만 동일 장소로 인정한다.
3. 카카오에 없다는 사실만으로는 폐업 처리하지 않고 확인 필요로 둔다.
4. 행정 원천 후보가 여러 개라 동일 장소를 확정하지 못하면 확인 필요로 둔다.
5. 공공·고정·인프라 시설은 공식 변경 근거가 없으면 운영으로 유지한다.
6. ATM, 충전소, 주차장, 세차장, 화장실처럼 역할이 다른 부속 시설은 본 매장과 같은 장소로 매칭하지 않는다.

## 검색·매칭 보완

- 편의점 브랜드와 지점 표기를 정규화했다.
- 법인명·지점명·업종 접미사 차이를 검색 후보에 반영했다.
- 동일 주소와 유사 상호 후보는 장소 역할까지 확인한다.
- 행안부의 중복 인허가 후보는 동일 장소 식별이 확실한 경우만 결론에 사용한다.
- 카카오 재검증 큐를 DAG 안에서 자동 생성·재개한다.

## 최신 검증 결과

| 상태 | 건수 |
|---|---:|
| 영업 | 35,890 |
| 운영 | 14,842 |
| 확인 필요 | 5,675 |
| 폐업 | 1,582 |
| 전체 | 57,989 |

- 서비스 대상: 50,732건
- 확인 필요: 카카오 미발견 5,316건, 행정 후보 미해결 359건
- 폐업: 명시적 행정 원천 폐업 근거가 있는 1,582건

## 출력 구조 변경

최종 공개 출력은 내부 추적 열을 섞지 않는다.

- 서비스용 파일: 현재 입력 양식, 영업·운영만
- 전체 상태 파일: 현재 입력 양식 + `operating_status`
- 판정보존 목록: 상태와 근거 추적에 필요한 8열만

## 검증

- 단위 테스트 56개 통과
- 서비스 파일에는 영업·운영만 포함되는지 검증
- 전체 상태와 판정보존 목록의 상태값을 검증
- 폐업이 공공·고정·인프라 규칙을 위반하지 않는지 검증
